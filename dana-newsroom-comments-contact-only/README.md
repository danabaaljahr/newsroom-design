# دانه بالجهر | أعمال صحفية

نسخة True Editorial:
- تصميم أقرب لموقع صحفي شخصي.
- واجهة بدون تضخيم مبالغ.
- مادة رئيسية + مختارات + أرشيف.
- بحث وفلترة وحفظ وقراءة.
- متجاوب للجوال والابتوب.


## آخر تعديل
تم تصغير العنوان، تقليل الفراغ قبل المادة الرئيسية، وتهذيب بطاقة المادة الرئيسية.


## تعديل أخير
تم نقل بطاقات الأخبار/المقالات/التقارير بعد الإحصائيات مباشرة، وإزالة قسم الوسوم.


## تعديل
تم إزالة الفراغ الجانبي في قسم أحدث المواد وجعل البطاقات تستخدم عرض الصفحة كاملًا.


## آخر تعديل
- تقليل شبكة بطاقات أحدث المواد إلى عمودين على الشاشات الكبيرة لإزالة الفراغ الجانبي.
- جعل عنوان القسم ثم أدوات البحث والترتيب في صف تحته بشكل أنظف.


## التعديلات الجديدة
- إزالة روابط التنقل العلوية المتكررة والإبقاء على زر تصنيفات سريع + زر تواصل.
- إضافة قسم تواصل واضح في أسفل الصفحة.
- إضافة نموذج تعليقات لكل مادة داخل نافذة القراءة، مع حفظ محلي في المتصفح.

- حذف الزر العلوي بجانب الرئيسية/الشعار، والإبقاء فقط على قسم التواصل وخانة التعليقات.
